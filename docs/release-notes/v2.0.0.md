Lucent 2.0 is a ground-up rewrite. Notifications that don't nag, they glow.

![Lucent's Dawn, Daybreak and Graphite Themes](https://raw.githubusercontent.com/CPT-Dawn/Lucent/v2.0.0/docs/screenshots/hero.png)

```sh
paru -S lucent-bin   # prebuilt, x86_64
paru -S lucent       # from source, x86_64 and aarch64
```

Then run `lucent demo` and watch the show.

## What's new

- **A new Popup.** App icon, name, relative time, summary and body on a glassy card. Album art gets a small app badge. Bodies render bold, italic and links, and a long body is clamped to three lines.
- **Every common Notification feature works.** Icons from your icon theme, file paths or image data. Action buttons in a full-width row. A progress ring traced around the icon. Critical Popups get a coloured edge and a gentle pulse, and stay until you dismiss them.
- **Calm motion.** Popups slide in, fade out and the stack glides into place. A countdown line shows the time left, and hovering a Popup pauses it. Reduced-motion settings are respected.
- **Three Themes:** Dawn, Daybreak and Graphite. The default, `theme = "auto"`, uses Dawn in dark mode and Daybreak in light mode, and switches live with your system.
- **History.** Lucent remembers your last 100 Notifications (in memory only, never on disk). `lucent history`, `lucent history --json`, `lucent restore [ID]` and `lucent clear`.
- **Do Not Disturb.** `lucent dnd on|off|toggle` sends Notifications straight to History. Critical ones still get through unless you set `allow_critical = false`.
- **Overflow.** At most `max_visible` Popups at once; the rest wait behind a "+N more" pill.
- **Rules.** Per-app Rules can match on app name and summary, then change the timeout or Urgency, hide the Popup, or keep the Notification out of History.
- **A real command line.** `lucent demo`, `check`, `reload`, `dismiss [--all]`, `restore`, `history`, `clear`, `dnd` and `status [--follow]`. `status --follow` streams JSON for a Waybar module without polling.
- **Friendlier config.** Every key is optional. Lucent writes a fully commented config on first start, applies edits when you save them, and keeps the last good config if you save a broken one. `lucent check` points at the exact line and suggests a fix. Add a `style.css` next to it for full control.
- **Plays nicely.** If mako, dunst or swaync already owns the notification name, Lucent tells you which one and how to switch, then steps aside.
- **Packaging.** Releases now publish both `lucent` (built from source) and the new `lucent-bin` (prebuilt) to the AUR automatically.

## Fixed from v1

- Icons are drawn. v1 advertised `icon-static` but never drew an icon.
- Actions are shown and send `ActionInvoked`.
- `CloseNotification` sends `NotificationClosed` once, and never for ids that don't exist.
- Adding a config key no longer breaks older config files.
- The README no longer points at a missing GIF or placeholder badges.

## Upgrading from v1

Your v1 config keeps working: Lucent starts with its defaults and prints a one-line warning for each v1 key, naming its replacement. Run `lucent check` to see them all, then move your settings across:

| v1 key | v2 replacement |
| --- | --- |
| `width = 350` | `width` under `[popup]` (default now 380) |
| `timeout_seconds = 5` | `low`, `normal` and `critical` under `[timeout]` (defaults 3, 5 and 0, where 0 means "until dismissed") |
| `background_color` | `theme = "dawn"`, `"daybreak"` or `"graphite"`, or `background-color` on `.popup` in `style.css`. To make a Theme more see-through, use `opacity` under `[look]` |
| `border_color` | `theme`, or `border-color` on `.popup` in `style.css` |
| `border_width` | `border-width` on `.popup` in `style.css` |
| `text_color` | `theme`, or `color` on `.popup` in `style.css` |
| `corner_radius = 12` | `radius` under `[look]` (default now 14) |
| `font_family = "Inter"` | `font` under `[look]` (default now your system UI font) |
| `max_visible_notifications = 5` | `max_visible` under `[popup]` |

For example, this v1 config:

```toml
width = 400
timeout_seconds = 8
corner_radius = 8
font_family = "Inter"
max_visible_notifications = 3
```

becomes:

```toml
[popup]
width = 400
max_visible = 3

[timeout]
normal = 8

[look]
radius = 8
font = "Inter"
```

Other changes to know about:

- **Timeouts follow Urgency.** v1 used one timeout for everything. In v2, low Notifications leave after 3 seconds, normal ones after 5, and Critical ones stay until you dismiss them. An app that sets its own timeout still wins, unless a Rule overrides it.
- **Lucent stays running.** D-Bus still starts Lucent when the first Notification arrives, so you don't need an autostart entry. Once started it keeps running, because History and Do Not Disturb live in memory. (v1's README said it exited when idle. It never did.)
- **Hyprland blur rules.** The `layerrule = blur, lucent-notification` lines from the v1 README use syntax that current Hyprland rejects. The README has updated snippets for Hyprland, Sway (SwayFX) and niri. The layer-shell namespace is still `lucent-notification`.
- **Requirements.** GTK 4.22 or newer and gtk4-layer-shell. GNOME isn't supported, because it has no layer-shell.
